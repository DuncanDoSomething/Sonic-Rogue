# Roadmap

## Done
- [x] Turn-based battles with move animations, crits, misses and battle speed settings
- [x] Boost meter (max 6), with an ultimate per character from level 30
- [x] Stat stages for ATK, DEF, SPD and accuracy (-6 to +6)
- [x] Speed / Fly / Power types
- [x] Nine zones from Sonic Advance 2 and 3, with zone effects
- [x] Zone bosses and Chaos Emeralds
- [x] Team of three with switching, KOs and Exp. Share
- [x] Rivals that unlock characters and can join your team
- [x] Shop with prices that scale per zone
- [x] Sonic Advance 2-style intro, music and sound effects
- [x] Passives for every character, plus unique ultimate effects
- [x] Stuns, team heals and moves that change your own stats
- [x] Character kit screen (I) in battle and character select
- [x] Ultimate cut-ins and animations, impact effects and hit-stop
- [x] Pause menu, KOs that last until the zone boss, Revive item
- [x] Test mode (?test) with battle hotkeys
- [x] Layered idles, smooth Sonic and Amy idles, attack flow (run-ups, knockback, landings) and upgraded move animations
- [x] Shop rebalance: percentage heals, two-item bag
- [x] Auto-save after every wave, Save & Quit in the pause menu and Continue on the title screen
- [x] Reward revamp: five rarity tiers, buffs, level-ups, Move Chip, PokéRogue-style money curve (see [docs/design/rewards.md](docs/design/rewards.md))
- [x] Balance pass: faster Sonic, stronger Knuckles (Fired Up), free items (1 per fight), heals for any teammate, flat-or-percent heals, better boss rewards
- [x] Boss recovery: 50% patch-up after zone bosses, full heal and 3+ Boost after waves 20/40/60/80
- [x] Random zone order per run (fixed start, shuffled mid / mid-late / end groups)
- [x] Sonic-style battle HUD: ring counter, bag and buff icons on screen with hover info, Boost in the party menu and during rewards
- [x] How to Play by topic, a guided practice fight with Tails, and one-time tips (can be turned off)
- [x] Unit tests, end-to-end tests and automatic deploys
- [x] Shadow as a playable character (Chaos Spear, Chaos Control, Super Shadow ultimate, Ultimate Lifeform passive)
- [x] Main bosses every 20 waves: Dr. Eggman in X-Zone / XX, rarely Shadow instead (unlocks him), PokéRogue-style boss shields
- [x] Balance pass: enemies scale per zone, more (and later stronger) rivals, full EXP for everyone who fought, Shadow nerfs
- [x] Toss items from your bag, voice lines for Shadow, spin balls for Knuckles and Shadow
- [x] Chaos Emeralds give the bench +5% EXP each; Eggman's Egg Mobile gets a random type
- [x] New animations for every team move (1 Boost and 2-3 Boost), Amy and Shadow buffs
- [x] Cream rework: Chao Attack (Cheese as a weapon), cheaper Chao Cheer with +1 Boost, Chao Blessing revives and powers up the team
- [x] Balance simulation (`npm run sim`) and a balance pass from it: Glove Punch stuns once per fight, Sonic dodges and has more HP, Amy is sturdier and keeps her ATK raises, Shadow's Ultimate Lifeform, Iron Fists only from above half HP, stronger 1-Boost moves
- [x] Rival update: 2 shields, a trick per rival, never the same rival twice in a row
- [x] Enemy variety: every badnik plays differently (Hard Shell, Charge with an intent icon, Spikes, Piggy Bank, poison, freeze, Boost drain, stat drops, first strike), Shell Tank's Shell Up, and elites with a random trait (Armored, Enraged, Regenerating, Swift)
